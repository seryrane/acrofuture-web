# 배포 — GitHub Pages

`main` 에 밀면 GitHub Actions 가 굽고 Pages 가 낸다. **사람이 빌드해서 올리지 않는다.**
빌드 산출물(`site/out`)을 저장소에 넣지 않는 이유가 이것이다 — 누가 한 번 빌드를 잊으면
"고쳤는데 옛 화면이 나온다"가 되고, 그건 보는 사람에게 사이트가 고장 난 것으로 보인다.

```
로컬에서 고침 ──▶ git push origin main
                      │
                      ▼
        .github/workflows/deploy.yml
        npm ci ──▶ npm run build ──▶ site/out ──▶ Pages
                   (output:'export')
                      │
                      ▼
                acrofuture.com
```

## 한눈에

| 항목 | 값 |
|---|---|
| 저장소 | `seryrane/acrofuture-web` (공개) |
| 배포 방식 | GitHub Actions (Pages source = **GitHub Actions**, 브랜치 배포 아님) |
| 도메인 | `acrofuture.com` — `site/public/CNAME` 에 박혀 있다 |
| 빌드 | `site/` 에서 `npm ci && npm run build` → `site/out` |
| 배포 시간 | 대략 1~2분 |

상태 보기: `gh run list -L 5` · 실패 로그: `gh run view --log-failed`

## DNS — 도메인을 GitHub 로 돌릴 때 (사람이 하는 일)

⚠ **이건 운영 사이트를 갈아끼우는 작업이다.** 지금 `acrofuture.com` 이 가리키는 곳의
레코드를 먼저 적어 두고 바꾼다(되돌릴 때 필요하다).

apex(`acrofuture.com`)는 CNAME 을 쓸 수 없어 A/AAAA 로 박는다.

```
A     acrofuture.com   185.199.108.153
A     acrofuture.com   185.199.109.153
A     acrofuture.com   185.199.110.153
A     acrofuture.com   185.199.111.153
AAAA  acrofuture.com   2606:50c0:8000::153
AAAA  acrofuture.com   2606:50c0:8001::153
AAAA  acrofuture.com   2606:50c0:8002::153
AAAA  acrofuture.com   2606:50c0:8003::153
CNAME www              seryrane.github.io
```

바꾼 뒤 저장소 **Settings → Pages → Custom domain** 에 `acrofuture.com` 을 넣고
DNS 검사가 초록이 되면 **Enforce HTTPS** 를 켠다.

- 인증서 발급은 DNS 전파 뒤 **몇 분~한 시간**이 걸린다. 그 사이에는 https 가 경고를 낸다.
  급하면 먼저 http 로 확인하고, HTTPS 강제는 초록이 된 다음에 켠다.
- Cloudflare 를 프록시(주황 구름)로 쓰면 GitHub 이 도메인 검증을 못 해 인증서가 안 나온다.
  **DNS only(회색 구름)** 로 둔다.

## 임시 공개 터널과의 관계

`acro.stock-autotrade.com`(Cloudflare 터널 → localhost:3100)은 **이 PC 가 켜져 있어야만**
뜨는 검토용 통로다. Pages 로 옮기고 나면 역할이 겹치므로, 도메인 전환이 끝나면 끈다.
켜고 끄는 법은 메모리 `acrofuture-web-tunnel` 에 있다.

## 저장소에 없는 것

`research/`(회사 소개서 PDF·추출 이미지 53MB)는 **올리지 않았다.** 공개 저장소라
소개서 원문이 통째로 배포되는 것을 피했다.

- 빌드·배포에는 지장 없다 — 구워 놓은 `site/public/media` 는 저장소에 있다.
- ⚠ 캡처를 **다시 구우려면**(`scripts/build-media.mjs`) 원본이 있는 이 PC 에서 해야 한다.
  다른 PC 에서 필요하면 `research/` 를 따로 복사해 온다.
