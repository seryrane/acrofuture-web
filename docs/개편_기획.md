## 0. 이 개편이 푸는 문제

지금 사이트는 **템플릿은 멀쩡한데 할 말이 없어서** 빈약해 보인다. 전체 글자가 707자다.
회사 소개서에는 16년치 사업 이력과 고객사·인증·특허가 있는데 홈페이지에는 한 줄도 없다.

그래서 이번 개편의 성격은 이렇다.

> **"예쁘게"가 아니라 "있는 실력을 보이게".** 디자인은 그것을 담는 그릇이다.

동시에 **업무 포탈로 들어가는 문**을 이 사이트에 낸다. 밖에서 온 사람에게는
"이 회사는 자기 플랫폼을 만들어 쓴다"는 증거가 되고, 임직원에게는 상시 진입점이 된다.

## 2. 정보 구조 (IA)

한 장짜리 앵커 사이트를 **페이지로 가른다.** 검색으로 들어올 문이 하나뿐이던 것을 여러 개로 만든다.

```
/                     홈 — 한 줄 주장 + 숫자 + 대표 사례 3 + 고객사 + 포털 문
├─ /about             회사 소개 — 개요·연혁(전체 연표)·조직·인증/특허
├─ /business          사업 영역 — 금융 IT · 모빌리티 · LBS/솔루션
│   ├─ /business/finance
│   ├─ /business/mobility
│   └─ /business/lbs
├─ /works             사업 사례 — 최근 3년 상세(필터: 고객사·영역·연도)
│   └─ /works/[slug]  사례 상세 — 무엇을·왜·어떻게·결과
├─ /solutions         자체 솔루션 — AcTrack · Cacago · Smart Zone Cast
├─ /careers           인재영입 — 사람·문화·채용공고(사람인 연결)
├─ /contact           오시는 길 · 문의
└─ [업무 포탈] →      사내 포털 로그인 (외부 도메인)
```

**왜 이렇게 가르나**
- `/works` 가 이 회사의 **가장 강한 자산**이다. 지금은 존재하지 않는다.
- 사업 영역을 페이지로 나눠야 "금융 IT 개발사"·"LBS 전문"으로 각각 검색에 걸린다.
- 채용은 별도 페이지가 있어야 공고 링크만 갈아끼우며 오래 쓴다.

## 4. 업무 포탈 게이트

- 자리: **헤더 오른쪽 끝**, 다른 메뉴와 구별되는 버튼(면 채움). 모든 페이지에 상시.
- 동작: 포털 로그인으로 이동(새 탭). 사내 계정이 없으면 로그인 화면이 알아서 막는다.
- 문구: 외부인이 봐도 뜻이 통하게 — "업무 포탈"(임직원용)이라고 **대상**을 밝힌다.
- ⚠ **회사 소개와 업무 도구를 섞지 않는다.** 게이트는 문일 뿐, 포털 내용을 홈페이지에 끌어오지 않는다.

## 5. 디자인 방향

지금 사이트의 인상(다크 히어로 + 육각형 그래픽 + 청록 포인트)은 **2018년쯤의 IT 회사** 느낌이다.
바꿀 축은 셋이다.

| 축 | 지금 | 바꿀 방향 |
|---|---|---|
| 글꼴 | Lato(영문 전용) → 한글 폴백 | **한글 본문용 글꼴을 1순위로**(Pretendard 계열). 영문·숫자만 라틴 폰트 |
| 폭 | 1140px 고정 | 넓은 화면을 쓰되 **글줄은 65자 내외**로 — 폭이 아니라 리듬으로 채운다 |
| 색 | 남색+청록, 히어로만 다크 | 밝은 바탕 기본 + **한 곳에만 강조색**. 다크는 사례·솔루션 구간에서 대비로 |

지킬 것: **가로 스크롤 0**(지금 429px 넘친다 — 원인은 클리핑 안 된 슬라이더),
`description`·Open Graph 채우기, `h1` 은 페이지당 하나.

## 6. 만드는 순서

1. **원문 조사 마무리** — 연혁 전체·인증·특허·포트폴리오 (진행 중)
2. **콘텐츠 정리** — 사례 카드에 들어갈 문장을 사람 말로 쓴다(가장 오래 걸리는 일)
3. **디자인 시안** — 홈·사례 목록·사례 상세 3화면을 먼저 본다
4. **구현** — Next.js 정적, 콘텐츠는 파일(MDX/JSON)로 두어 나중에 손으로 고칠 수 있게
5. **점검** — 가로 넘침·모바일·검색 메타·링크 미리보기·성능

## 7. 아직 안 정한 것 (일부는 9절에서 결정됐다)

- 로고를 손볼지(지금 것을 그대로 쓸지)
- 영문 페이지가 필요한지 (고객사에 글로벌 사업이 있다)
- 사례 상세에 **화면 이미지**를 실을 수 있는지 — 고객사 화면은 대개 공개 제약이 있다
- ⚠ **AcTrack · Cacago** — 지금 홈페이지에는 있는데 **회사 소개서 어디에도 없는 이름**이다.
  계속 쓸 브랜드인지, 이름을 바꿀지, 뺄지 확인이 필요하다. (Smart Zone Cast 는 사업 이력에 있어 근거가 있다)
- 업무 포탈 주소는 정해졌다 — **아크로퓨처 PoC 포털 서비스 서버** `http://211.236.39.250:3400/`
  (사용자 지정 2026-08-06, 확인 시 200). 남은 것은 **https 와 도메인**이다: 지금은 TLS 가 없어
  로그인 정보가 그대로 지나가고, IP 가 바뀌면 홈페이지 값도 같이 고쳐야 한다.

## 8. 안 하기로 한 것 (이유와 함께)

- **문의 폼** — 받는 서버가 없다. 폼이 있는데 안 가는 것이 없는 것보다 나쁘다. 전화·이메일로 안내한다.
- **지도 스크립트** — 정적 배포이고 외부 스크립트는 방문자 정보를 흘린다. 주소 + 지도 검색 링크로 대신한다.
- **목록·검색·채용·문의의 스크롤 연출** — 목적이 분명한 화면에서 연출은 방해다.
