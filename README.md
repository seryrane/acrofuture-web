## 구성

```
site/                 Next.js 16 (App Router) · Tailwind 4 · 정적 내보내기
├─ src/content/       ⚠ 콘텐츠 정본 — 화면은 여기 없는 숫자를 쓰지 않는다
│   ├─ company.ts     회사·인력·조직·사업영역·인증/특허/수상
│   ├─ works.ts       사업 이력 101건 + 고객사·연도 파생값(코드로 계산)
│   ├─ showcase.ts    실제 구축 화면 — 소개서 포트폴리오 캡처 ↔ 사업 매핑
│   ├─ solutions.ts   자체 솔루션 3종 + **근거**(특허·사업 이력)
│   └─ stats.ts       화면에 나오는 숫자를 한 곳에서 센다
├─ src/components/
│   ├─ home/          홈의 9개 구간
│   ├─ ui/Section.tsx 구간·머리·카드 (여백과 리듬을 여기 가둔다)
│   └─ Header·Footer·Rise·FieldArt
├─ src/app/           / (한 페이지) · /works · /works/[slug] · /careers
└─ public/media/
    ├─ credentials/   증서 실물 7장
    └─ works/         구축 화면 캡처 29장 ← scripts/build-media.mjs 가 굽는다
research/             원문 PDF·페이지 이미지·전수 조사·추출이미지 39장
scripts/build-media.mjs  추출이미지 → webp 변환 (사업 이름으로 개명)
```

## 실행

```bash
cd site
npm install
npm run build    # 정적 산출물 → site/out
node ../scripts/build-media.mjs   # 캡처를 다시 구울 때만
```

⚠ **검토용으로 `npm run dev` 를 띄우지 않는다.** 개발 서버는 서버 쪽 모듈을 따로 캐시해서
콘텐츠를 고쳐도 옛 값을 계속 내보낸다 — 보는 사람에게는 "예전 화면이 나온다"로만 보인다.
`npm run build` 뒤 `node scripts/serve-out.mjs 3100` 으로 **산출물 그대로** 낸다.

## 지키는 것

- **숫자는 데이터에서 센다.** 화면에 손으로 적지 않는다 — 이력이 늘었는데 숫자가 그대로면 거짓말이 된다.
- **색·치수는 토큰만**(`src/app/globals.css`). hex 직접 사용 금지.
- **가로 넘침 0.** 지금 사이트는 클리핑 안 된 슬라이더 때문에 429px 넘친다.
- **한글 글꼴이 1순위.** 지금 사이트는 영문 전용 글꼴이 1순위라 한글이 폴백으로 떨어진다.
- **인터랙션은 자리를 가려 쓴다** — 홈 구간에만. 목록·검색·채용은 정적.
- **없는 사실을 만들지 않는다.** 원문에 없으면 비워 두거나 "확인 필요"로 남긴다.
  성과 수치(“40% 단축”)는 잰 자료가 없으면 **안 쓴다.** 대신 기간·고객사·기술스택을 놓는다.
- **스톡 사진을 쓰지 않는다.** 실물 캡처가 있으면 실물을, 없으면 도표를 쓴다.
