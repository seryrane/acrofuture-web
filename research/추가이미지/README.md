# 여기에 이미지를 넣어 주세요

`scripts/build-media.mjs` 가 이 폴더를 보고 웹용으로 굽습니다.
**파일 이름을 아래 그대로** 맞춰 주세요(확장자는 png · jpg · webp 아무거나).

| 파일 이름 | 무엇 |
|---|---|
| `im-capital-web-live` | 지금 운영 중인 iM캐피탈 홈페이지 화면 (소개서 캡처를 이걸로 교체) |
| `ai-cc-1` | AI 고객센터 — 접수 내역 |
| `ai-cc-2` | AI 고객센터 — 무엇을 도와드릴까요 (서비스 선택) |
| `ai-cc-3` | AI 검색 — 이렇게 요청할 수 있어요 |
| `ai-cc-4` | AI 검색 — 질문 입력 |
| `ai-cc-5` | AI 검색 — 답변과 개인정보 입력 차단 |

넣은 뒤 저장소 루트에서:

```
node scripts/build-media.mjs
cd site && npm run build
```

## ⚠ 세로로 긴 그림은 위에서 잘라 씁니다
휴대폰 화면은 세로가 너무 길어서 통째로 올리면 카드 안에서 아주 작아집니다.
그래서 **가로:세로가 3:4 가 되도록 위에서부터** 잘라 씁니다 — 화면 머리와 첫 내용이
남아야 무슨 화면인지 설명이 됩니다(사용자 요청 2026-08-07).
자르는 비율은 `build-media.mjs` 의 `DROP_IN` 표에서 파일마다 바꿀 수 있습니다.
